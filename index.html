    หาไฟล์พวกนี้จากไหน? (KiCad / EasyEDA / Altium)

    KiCad — .kicad_pcb อยู่ในโฟลเดอร์โปรเจกต์ · Gerber: File → Fabrication Outputs → Gerbers (.gbr) + Generate Drill Files แล้ว zip รวม · BOM + CPL: ปลั๊กอิน Fabrication Toolkit (JLCPCB) หรือ File → Fabrication Outputs → Component Placement (.csv)

    EasyEDA — Fabrication → PCB Fabrication File (Gerber) · Fabrication → BOM · Fabrication → Pick and Place File (CPL)

    Altium — Gerber Files + NC Drill Files (zip) · Bill of Materials · Pick and Place Files

    💡 ใช้ไฟล์ชุดเดียวกับที่อัปโหลดสั่ง PCBA ที่ JLCPCB ได้เลย — ตำแหน่ง CPL จะถูกจัดให้ตรงกับ Gerber อัตโนมัติ

    ลากหลายไฟล์มาวางในหน้าต่างนี้ได้เลย ระบบจัดเข้าช่องให้เอง
